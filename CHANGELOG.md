# Changelog

## 0.7.0 / Create App 0.5.0 / Server 0.1.0

- Official backend clients for TypeScript/JavaScript, Python, PHP and Go.
- Interactive backend setup with Node/Express, FastAPI/Django, PHP HTTP and Go HTTP starters.
- Persistent inventories and charge receipts, verified sessions, raw signed webhooks and safe recovery.
- Server-managed seasonal leaderboards, read-only browser inventory, catalogue helpers and reward contexts.
- Test-session developer inspector and local payment/ad failure scenarios.
- Backend route contract and HTTP conformance suite across all four language clients.

Live provider-verified ad rewards additionally require a compatible native Lia build and AdMob SSV configuration. Native builds are not part of this package release.
